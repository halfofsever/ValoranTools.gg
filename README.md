**Account security is our top priority. ValoranTools.gg is built with a "Security-First" architecture.**
**账号安全是我们的首要关注。ValoranTools.gg 采用“安全至上”的架构设计。**

    * **EN**: We strictly use Riot Sign-On (RSO). We NEVER see, collect, or store your Riot password.
    * **CN**: 我们严格使用官方 RSO 登录，绝不接触、收集或存储您的账号密码。
