# Contributing to ValoranTools.gg | 参与项目贡献

First off, thank you for considering contributing to **ValoranTools.gg**! It's people like you who make this a great tactical companion for the global community.
首先，感谢您考虑为 **ValoranTools.gg** 做出贡献！正是有了您的参与，这个项目才能成为全球社区更好的战术助手。

---

## 🛠️ How Can I Contribute? / 我能贡献什么？

### 1. Reporting Bugs / 反馈问题
* **EN**: Use our [Issue Templates](https://github.com/halfofsever/ValoranTools.gg/issues) to report bugs. Be as descriptive as possible.
* **CN**: 请使用我们的[问题模板](https://github.com/halfofsever/ValoranTools.gg/issues)反馈错误，并尽可能详细地描述。

### 2. Suggesting Features / 功能建议
* **EN**: Have an idea for a new lineup or tool? Open a "Feature Request" issue to discuss it.
* **CN**: 有新的点位或工具想法？请发起“功能建议” Issue 与我们讨论。

### 3. Tactical Data Updates / 战术数据更新
* **EN**: We especially welcome high-rank players to contribute high-definition lineups and pro tips.
* **CN**: 我们特别欢迎高分段玩家贡献高清点位图及进阶实战技巧。

---

## 🚀 Workflow / 协作流程

1. **Fork the Repo**: Create your own copy of the project. / **派生仓库**：创建该项目的个人副本。
2. **Create a Branch**: Work on your changes in a new branch. / **新建分支**：在独立分支中开发您的改动。
3. **Submit a PR**: Open a Pull Request with a clear description of your changes. / **提交 PR**：提交合并请求并清晰描述您的改动。

---

## ⚖️ Code of Conduct / 行为准则

* **EN**: We are committed to fostering an open and welcoming environment. Please be respectful to all community members.
* **CN**: 我们致力于建立一个开放且友好互助的社区环境。请尊重所有社区成员。
